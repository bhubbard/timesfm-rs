timesfm-rs — Native Rust Inference Engine for Google Research's TimesFM Foundation Model

timesfm-rs is a pure Rust time-series forecasting engine that runs Google Research's patched-decoder TimesFM foundation model 13.4× faster than Python/JAX. It performs zero-shot univariate and multivariate forecasting with quantile uncertainty intervals on CPU and Apple Silicon Metal GPUs.

$ cargo add timesfm-rs
GitHub ↗

⚡ Zero Python / JAX Overhead

Runs as a standalone compiled native binary. Completely bypasses Python GIL, PyTorch/JAX runtime initialization, and XLA JIT pauses.

🍏 Apple Silicon Metal Acceleration

Direct Metal Performance Shaders (MPS) kernels and unified memory zero-copy tensor sharing.

📊 Statistical Parity

Maintains exact parity with Google Research TimesFM weights (MAE Δ < 0.0001, identical CRPS quantile distributions).

🛰️ Edge & Embedded Ready

Consumes less than 600 MB RAM for 500 parallel series, making it ideal for edge gateways and local financial monitoring.

🎯 Conformal Calibration & Anomaly Detection

Built-in Conformalized Quantile Regression (CQR) for finite-sample coverage guarantees, zero-shot inter-decile anomaly detection, and classical seasonal decomposition.

🤝 Statistical Baselines & Ensembling

Includes Naive, SeasonalNaive, Drift, and Holt-Winters forecasters plus an inverse-MAE backtest-weighted EnsembleForecaster with Vincentized quantiles.
